# FluNET 1.0 contract plan

1.0 is a compatibility milestone rather than a feature dump. Batches 76–83 formalize and verify the contracts that already power the compiler/runtime.

The freeze covers:

- stable command/frame/type identifiers;
- canonical and compact syntax boundaries;
- separator/expression precedence contracts;
- module/provider/codec/conversion/action extension APIs;
- security/capability responsibilities;
- workflow/schedule/cache/idempotency/history persistence boundaries;
- compatibility/deprecation policy;
- package/module boundaries;
- complete CLI command routing;
- cross-platform restore/build/test and contract snapshots.

`LanguageVersion = 1.0` is only permitted after Batch 83 verification succeeds on the exact release tree.
